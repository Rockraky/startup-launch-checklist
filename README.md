# Startup Launch Checklist

A practical checklist to help founders prepare, launch, and promote their startup.

## 1. Product Readiness
- [ ] Test the main user journey from signup to first successful action.
- [ ] Check forms, login, password resets, and payments.
- [ ] Explain what your product does and who it helps.
- [ ] Publish clear pricing and usage limits.
- [ ] Provide a working support contact.

## 2. Website Readiness
- [ ] Use HTTPS across your website.
- [ ] Check the website on mobile and desktop.
- [ ] Fix broken links and missing pages.
- [ ] Compress large images and check loading speed.
- [ ] Publish appropriate privacy policies and terms.

## 3. SEO Basics
- [ ] Write a unique title and meta description for important pages.
- [ ] Use a clear main heading on each page.
- [ ] Check that public pages can be crawled and indexed.
- [ ] Review robots.txt and canonical tags.
- [ ] Create an XML sitemap.
- [ ] Connect Google Search Console and submit the sitemap.

## 4. Analytics
- [ ] Install your analytics tool.
- [ ] Confirm visits are recorded correctly.
- [ ] Track important actions such as signups and purchases.
- [ ] Follow applicable consent requirements.
- [ ] Record baseline traffic and conversion numbers.

## 5. Launch Materials
- [ ] Prepare a short and detailed product description.
- [ ] Create a logo and clear product screenshots.
- [ ] List your target audience and main use cases.
- [ ] Prepare a launch announcement.
- [ ] Create campaign links to measure referral traffic.

## 6. Directory Submissions
- [ ] Choose directories relevant to your product and audience.
- [ ] Check submission rules, costs, and listing quality.
- [ ] Use accurate and consistent business information.
- [ ] Avoid duplicate listings and irrelevant submissions.
- [ ] Track submission dates, listing URLs, and approval status.
- [ ] Measure referral visits and signups from approved listings.

## 7. After Launch
- [ ] Respond to customer questions and feedback.
- [ ] Review signup and payment errors.
- [ ] Monitor Search Console for indexing issues.
- [ ] Identify which channels bring engaged visitors.
- [ ] Improve your product and messaging using real feedback.
